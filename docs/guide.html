Guide

Everything you need to go from a fresh install to a drawer full of labels.

Install

Download the installer for your computer from the download section or the latest release on GitHub.

Windows

Run the .exe installer. The app isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click More info, then Run anyway. Use the .msi if you deploy software with Group Policy or Intune.

macOS

Open the .dmg and drag LabelPad into Applications. Because the app isn't notarized yet, macOS blocks the first launch. Open System Settings → Privacy & Security and click Open Anyway. If macOS says the app "is damaged", run this once in Terminal:

xattr -cr "/Applications/LabelPad.app"

The first time you connect, macOS asks for permission to use Bluetooth. Allow it.

Linux

Use the .AppImage on any distribution (make it executable with chmod +x), or install the .deb or .rpm. Bluetooth goes through BlueZ, so the Bluetooth service must be running and your user needs access to it, usually by being in the bluetooth group.

Connect the printer

  1. Turn the printer on. You don't need to pair it in your system's Bluetooth settings.
  2. Click Connect printer in the top right. Printers nearby appear in a list, and the one you used last is marked.
  3. Pick your printer. The header shows its name and battery, and the right panel shows the loaded label roll.

The editor

The window has three parts. On the left are the things you can add. In the middle is the label, drawn at the printer's real resolution (8 dots per millimetre on the D11, about 12 on the M3), so the preview is exactly what prints. On the right, the panel changes with what you've selected: the label's size when nothing is selected, or the settings of the item you clicked. The print controls sit at the bottom of that panel.

Drag items to move them, pull the handles to resize, and use the round handle to rotate. Items snap to the label's edges, its center, and each other. Undo and redo cover every change.

With nothing selected, the right panel sets the label size. Choose the printer the label is for (D11 or M3), then pick one of its common sizes or type your own width and length in millimetres. Connecting a different printer offers to convert the label, and it's converted automatically when it prints.

What you can add

ItemWhat it does
TextAny font installed on your computer, bold or italic, aligned left, center or right and top, middle or bottom. Fit text to box sizes it to fill the box, and White on black inverts it.
DateThe date and/or time at the moment you print. See Dates and times.
ImageAny picture from your computer. Dither keeps shading in photos; threshold gives clean edges for logos, with a slider for how dark counts as black.
BarcodeCode 128, Code 39, EAN-13, EAN-8, UPC and ITF-14, with or without the number underneath.
QR codeAny text or link. Keep it short on a 12 mm label so it scans reliably.
IconA searchable set of clean line icons: boxes, food, cables, tools, pets and more.
ShapeRectangles, ellipses and lines, outlined or filled, for borders and dividers.

Choosing a font

The font list in the text panel shows popular fonts first, then everything else installed. Click Browse to see every font with your label's text as the preview, filtered by style.

Dates and times

A date item fills itself in when you print. Choose Date + time, Date or Time, then a date format. System format follows your computer's region settings. Times print as hours and minutes, in 12-hour or 24-hour form.

Text before adds words such as Made or Use by, and Add days moves the date forward, which is how the Food container template prints a use-by date three days out.

To make your own format, type a pattern with these tokens. Anything else prints as written.

Numbered labels

Put {count} anywhere in text, a barcode or a QR code. The + Number link under the text box adds it for you.

  • Printing 3 copies of Box {count} gives Box 1, Box 2 and Box 3.
  • {count:3} pads the number to three digits: 001, 002, 003.
  • Start at and Count by appear in the print panel once a label has a number.
  • After printing, the counter moves on, so the next print continues where the last one stopped. It's saved with the label.

Selecting and aligning

Shift-click items to select several, or drag a box around them from an empty part of the label. Drag any selected item to move them all together.

The panel then offers alignment. To each other lines the items up with the outer edges of the selection; To the label lines them up with the label itself. Distribute spaces items evenly, which needs three or more when aligning to each other. A single item can be centered on the label from its own panel.

Templates and files

New (Ctrl+N) opens the template gallery: a blank label, the built-in templates, and any label you saved with Save as template.

Labels save as .labelpad files, in Documents\LabelPad unless you pick another folder in Settings, that you can keep, share and open again. The label you were working on reopens when you start the app, even if you never saved it. You can turn that off in Settings.

Printing and label rolls

Choose a darkness from 1 to 3 and the number of copies, then click Print or press Ctrl+P. If labels come out faint, raise the darkness; if fine detail bleeds together, lower it.

Genuine Niimbot rolls carry an RFID tag. Once connected, the app shows how many labels are left on the roll. The tag doesn't say how big the labels are, so the first time you load a type of roll the app asks once and remembers. After that, if your label doesn't match the roll, it offers to switch.

Settings

The gear icon in the top right opens Settings: light, dark or system theme, whether to reopen your last label at startup, and updates. Darkness, copies, label size and your printer are remembered automatically.

Updates

Once a week LabelPad checks for a new version. When there is one, it shows what's new and asks: Update now downloads it and restarts the app, and Later asks again next week. Use Check now in Settings to look straight away, or turn the weekly check off. On Linux, the AppImage updates itself; if you installed the .deb or .rpm, the app links you to the new package instead.

Troubleshooting

The printer doesn't appear in the list

Make sure it's on and not connected to your phone; a Niimbot printer talks to one device at a time. Close the Niimbot phone app or turn off your phone's Bluetooth, then try again. Check that Bluetooth is on in your computer's settings.

It connects, then drops

Move closer, and charge the printer if the battery is low. Disconnect and reconnect from the header.

The print is shifted or cut off

Check that the label size in the editor matches the roll you loaded. The roll panel warns you when they differ.

Still stuck?

Open an issue on GitHub with your printer model, your operating system, and what happened.

Build from source

You need Node.js 22 or newer, Rust (stable), and the Tauri prerequisites for your system. On Linux that includes libwebkit2gtk-4.1-dev and libdbus-1-dev.

git clone https://github.com/derhally/labelpad
cd labelpad
npm install
npm run dev      # run with hot reload
npm run build    # build an installer for this system

The app is Tauri 2: a React and TypeScript editor in the system webview, and a Rust backend that talks to the printer over Bluetooth LE. The printer protocol is a Rust port of niimbluelib, tested byte for byte against it.

Releases are automatic. Commit messages follow Conventional Commits (feat:, fix:), and release-please turns them into a release pull request with the changelog. Merging it publishes the release and attaches installers for every platform.
